# artificial-intelligence-and-expert-systems
Repository of projects from Artificial Intelligence and Expert Systems course

# how to run external programs
External tools provided by professors are old, really old, so to run them properly you have to must have Java 8 which on some modern Java distributions may not work.

It is recommended to use Java Azul Zulu by Azul Systems which can be downloaded here: 
https://www.azul.com/downloads/zulu-community/?version=java-8-lts&architecture=x86-64-bit&package=jre-fx

# how to run verify_all mode
Verify all mode is again based on program provided by professors on wikamp, and it is not that but, but you still have to do some manual work to make it function properly. Change mentioned in comment paths for Java binary, resources (generated boards for 15-puzzle) and Jar for validator (again from wikamp).
I verified this script only on windows, so it may not work properly on unix based systems
